# アイス売上の集計サンプル

横浜店・銀座店・品川店のCSVファイルを読み込み、店舗・フレーバー別の集計表を作るPythonの練習用プロジェクトです。Excelや追加のPythonパッケージは必要ありません。CSVファイルはGoogleスプレッドシートなどでも開けます。

練習用に入力データは4行だけです。フレーバーはチョコ（450円）、ストロベリー（400円）、バニラ（350円）の3種類に限定しています。横浜店のバニラを2行にしているので、集計後に個数が合算される様子を確認できます。CSVの列名は日本語です。

## フォルダ構成

```text
ice/
├── data/
│   └── input/            店舗ごとの売上CSV
├── output/               集計結果CSV
├── summarize_sales.py    集計プログラム
└── README.md
```

## 実行方法（macOS）

ターミナルでこのフォルダ（`ice`）に移動して、初回だけ仮想環境を作ります。

```bash
python3 -m venv .venv
```

仮想環境を有効にして、集計プログラムを実行します。

```bash
source .venv/bin/activate
python summarize_sales.py
```

初回・再実行とも追加パッケージのインストールは不要です。処理が終わったら、次の2つのファイルが `output/` に作られます。

- `sales_summary.csv`：店舗・フレーバーごとの合計個数と合計売上

仮想環境を終了するときは `deactivate` と入力します。

## 入力ファイルを追加・変更する

`data/input/` にあるCSVを編集するか、同じ列名のCSVを追加します。列名は `フレーバー,個数,単価` です。ファイル名が店舗名になります（例：`横浜店.csv`）。フレーバーはチョコ（450円）、ストロベリー（400円）、バニラ（350円）のいずれかを使い、個数は0以上の整数を入力してください。

Googleスプレッドシートで作成した場合は、各店舗のシートをCSV形式でダウンロードし、このフォルダに保存します。新しいファイルを置いたら、もう一度プログラムを実行してください。
